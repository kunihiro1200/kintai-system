# 勤怠ルール

## 1. 基本ルール

1. **企業規定を基本に**
   パソコンで打刻できます。やむを得ない時以外はスマホでも可能。

2. **休日すぎる当月の打ち忘れは翌月初まで修正可能。**

3. **正田店舗内外行日に給料を支払う。休日下旬になります。**

4. **私から公休日は専務の許可が必要となります。公休日と重ねるための3日は必要です。当てることもあります。（休日処理の申請含め）**

5. **お盆、GW、年末年始などシーズンの年次以外は各店舗の実務として、出勤休日時間対応が必要となります。（休日処理の申請に必ず）**

6. **年次休暇の一斉取得時には、その前後に全体の休暇を準備されます。公式全体と統括部門と市に所属する時：その中の時期一斉をあり得ます。本人指定する公式の年明けるあります。**
   （注：休日処理・休日カレンダーに必ず予定）

7. **システムの従業員退出画面は有休カレンダーを表示します。同業や従業員全員の該当日分が見られ、その年度の日程に関して実現して可能な情報を管理します。**

8. **残業をできる従で働く時間の15時を除外。2分かかり行きたくない前のことになる体制にある従事しいといった場合。社内に配分しております。**

9. **もっとも時員全での社員レイアウトがもっと日は・年月、次のちなみちゃっており年休に該当しない。行って月の1日超え使の内給でありなります。ちなみなつかみるとことわらいその時。できる所動出分らして長時間るだアン会社があれるとあります。**

10. **残業に考るます。利用期限の6ヶ月以内（次の。昨日出を同等れていのための他のものにする必要あります。現在に修理される該当すると共同があり、午所の判断のを含めることができる。**

11. **残業に設した場合の残代のフォームにおいて以立業務員のと思いますとフィールをに所得することができます。**
    （注：当年・次、ストップ・カで制出年とフルタイム通は配列します。）

12. **成果物を持って進め必要。休業以前はの時期地の制約をします。**

## 2. 年末年始・お盆休みと個人休の取り扱い

**年末年始・お盆休みは特別休暇のため、個人休と重なった場合でも、代休の取得はできません。**

これは、会社が定める特別休暇期間（年末年始休暇・お盆休暇）は、既に会社都合による休日として設定されているため、個人の有給休暇や代休と重複して使用することはできないという規定です。

### 具体例

- 年末年始休暇：12月29日〜1月3日（会社カレンダーによる）
- お盆休暇：8月13日〜8月16日（会社カレンダーによる）

上記期間中に休日出勤の代休を取得することはできません。代休は通常の営業日に取得してください。
