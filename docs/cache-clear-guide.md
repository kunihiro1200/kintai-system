# ブラウザキャッシュのクリア方法

## 概要

勤怠管理システムで「休暇（6ヶ月以内社員）」ボタンのバグ修正を行いました。
修正を反映させるため、ブラウザのキャッシュをクリアしてください。

## キャッシュクリア方法

### 方法1: ハードリロード（推奨）

最も簡単な方法です。

**Windows / Linux:**
- `Ctrl + Shift + R` を同時に押す

**Mac:**
- `Cmd + Shift + R` を同時に押す

### 方法2: シークレットモード

ブラウザのシークレットモード（プライベートブラウジング）でアクセスすると、キャッシュを使用せずに最新版が表示されます。

**Chrome:**
- `Ctrl + Shift + N` (Windows/Linux)
- `Cmd + Shift + N` (Mac)

**Edge:**
- `Ctrl + Shift + N` (Windows/Linux)
- `Cmd + Shift + N` (Mac)

**Firefox:**
- `Ctrl + Shift + P` (Windows/Linux)
- `Cmd + Shift + P` (Mac)

## 確認方法

キャッシュクリア後、以下を確認してください：

1. 勤怠管理システム（https://kintai-system-pi.vercel.app）にアクセス
2. 「休暇（6ヶ月以内社員）」ボタンをクリック
3. 日付を選択して「保存」をクリック
4. 成功メッセージが表示されることを確認

## 問題が解決しない場合

上記の方法を試しても問題が解決しない場合は、システム管理者に連絡してください。
